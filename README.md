# Свой VPN одной командой

Скрипт превращает чистый зарубежный сервер в личный VPN для приложения **Happ** (Android, iPhone, Windows, macOS). На выходе — ссылка: открываете её на телефоне, нажимаете «Добавить в Happ», подключаетесь.

Что получится:
- три способа подключения на одном сервере: **Hysteria2** (основной), **XHTTP** и **Vision** (запасные, маскируются под обычный HTTPS);
- российские сайты и приложения идут напрямую, всё остальное — через VPN;
- полоска расхода трафика в Happ, общая для всех ваших устройств;
- сервер снаружи выглядит как обычный сайт с настоящим сертификатом;
- файрвол, защита SSH от перебора паролей, автообновления безопасности.

---

## Что нужно заранее

1. **Сервер (VPS) за границей** с публичным IPv4, от 1 ГБ памяти, система **Ubuntu 24.04** (подойдут Ubuntu 22.04, Debian 12 и 13). Образ берите чистый, без готовых сайтов и панелей.
   Хостер важен: сети многих крупных хостеров российские провайдеры замедляют. По замерам из Москвы в октябре 2026 года не замедлялся **Webdock** (тариф Essential, около €2/мес). Hetzner, Contabo, DigitalOcean, Vultr, Oracle и AWS (США) замедлялись.
2. **Логин и пароль (или ключ) от сервера** — хостер присылает их в письме или показывает в панели.
3. **Телефон** с приложением Happ: [Google Play](https://play.google.com/store/apps/details?id=com.happproxy) · [App Store (Россия)](https://apps.apple.com/ru/app/happ-proxy-utility/id6783623643) · [App Store (другие страны)](https://apps.apple.com/us/app/happ-proxy-utility/id6504287215).

## Установка — три шага

**1. Зайдите на сервер.**
- Windows: откройте PowerShell и выполните `ssh root@АДРЕС_СЕРВЕРА` (вместо `root` — логин из письма хостера, если он другой).
- macOS: то же самое в программе «Терминал».
- С телефона: приложение Termius.
- Или веб-консоль в панели хостера.

При первом входе ответьте `yes`, затем введите пароль (символы при вводе не видны — так и должно быть).

**2. Вставьте одну команду и нажмите Enter:**

```bash
curl -fsSL https://raw.githubusercontent.com/reme3/vpn-setup/main/install.sh | sudo bash
```

Установка идёт 3–7 минут. Скрипт сам всё ставит, настраивает и в конце проверяет, что все три способа подключения работают.

**3. В конце появятся ссылка и QR-код.** Откройте ссылку на телефоне (или наведите камеру на QR) → «Добавить в Happ» → в Happ нажмите большую кнопку подключения.

Проверка: сайт **ifconfig.me** показывает адрес сервера, а **2ip.ru** — ваш обычный адрес. Так и должно быть: российские сайты идут напрямую.

> **Запишите номер порта SSH из итогового сообщения.** Скрипт переносит SSH на случайный высокий порт, и в следующий раз заходить нужно так: `ssh -p ПОРТ root@АДРЕС_СЕРВЕРА`.
>
> **Ссылка из итогового сообщения работает как пароль.** Кто её получит, тот пользуется вашим VPN и расходует ваш трафик.

Показать ссылки и QR-код ещё раз (на сервере): `sudo vpn-info`

## Настройки (по желанию)

Пишутся перед `bash` в той же команде, например:

```bash
curl -fsSL https://raw.githubusercontent.com/reme3/vpn-setup/main/install.sh | sudo VPN_NAME="Petya" TRAFFIC_LIMIT_GB=2000 bash
```

| Настройка | Что значит | По умолчанию |
|---|---|---|
| `VPN_NAME` | имя VPN в Happ | `VPN` |
| `TRAFFIC_LIMIT_GB` | месячный лимит трафика по тарифу хостера, ГБ; `0` — безлимит | `1000` |
| `TRAFFIC_COUNT` | `out` — считать только исходящий трафик (так считает Webdock), `both` — весь | `out` |
| `STOP_AT_LIMIT` | `1` — выключать VPN до 1-го числа, когда лимит исчерпан | `0` |
| `SSH_PORT` | `random` — случайный высокий порт, `keep` — оставить как есть, или номер | `random` |
| `DOMAIN` | свой домен, если он уже указывает на сервер | находит имя сам |
| `TZ_NAME` | часовой пояс сервера (ночные перезагрузки в 04:30 по нему) | `Europe/Moscow` |

Настройки запоминаются. Повторный запуск команды ничего не ломает: ключи и ссылки остаются прежними, меняется только то, что вы передали.

## Если что-то не так

| Что случилось | Что делать |
|---|---|
| Hysteria2 перестал подключаться | В Happ выберите **XHTTP**, если и он не идёт — **Vision**. |
| Не работает ни один | Проверьте с другой сети (Wi-Fi ↔ мобильный). На мобильном интернете в зонах «белых списков» не работает никакой VPN. |
| Банковское приложение ругается на VPN | Happ → настройки → раздельное туннелирование → исключите приложение. |
| `sudo: command not found` | Вы зашли как `root` — уберите из команды слово `sudo`. |
| Скрипт завершился ошибкой | Прочтите текст ошибки: там написано, что делать. Можно просто запустить команду ещё раз — она продолжит с того же места. |
| «Let's Encrypt не выдал сертификат» | В панели хостера, в настройках файрвола (если он есть), откройте входящие **80/tcp, 443/tcp, 443/udp** и порт SSH, затем запустите команду ещё раз. |
| После установки не пускает по SSH | Заходите с новым портом: `ssh -p ПОРТ ...`. Если у хостера есть файрвол в панели — откройте этот порт там. Вернуть 22-й порт: зайдите через веб-консоль хостера и выполните команду установки с `SSH_PORT=22`. |
| Сервер на Webdock, веб-терминал в панели перестал пускать | Укажите в панели Webdock новый порт SSH из итогового сообщения. |
| Ссылка утекла | Выполните команду установки с `ROTATE_KEYS=1` (вместо `VPN_NAME=…` в примере выше): все ключи и ссылки сменятся, старые перестанут работать. На своих устройствах удалите старую подписку в Happ и добавьте новую. |

Журнал установки: `/var/log/vpn-setup.log` (последние строки: `sudo tail -n 60 /var/log/vpn-setup.log`).

### Для ИИ-помощника

Ты помогаешь новичку. Сам ты к серверу не подключаешься — человек выполняет команды и присылает тебе вывод.

**Порядок работы**
1. Узнай: хостер, система сервера (нужна Ubuntu 22.04/24.04 или Debian 12/13), чем человек заходит (Windows PowerShell, macOS «Терминал», Termius на телефоне, веб-консоль хостера), есть ли логин и пароль.
2. Помоги зайти по SSH: `ssh ЛОГИН@IP`. Если вход под `root`, `sudo` в команде можно не писать.
3. Дай команду установки из README. Если человек называет лимит трафика по тарифу — добавь `TRAFFIC_LIMIT_GB=…` (см. таблицу настроек).
4. Попроси прислать **итоговый блок** вывода. В нём ссылка `https://…/add`, ссылка `…/sub` и номер порта SSH. Объясни: открыть `…/add` на телефоне → «Добавить в Happ» → подключиться. Попроси записать порт SSH. Предупреди, что ссылки — как пароль.
5. Проверка на телефоне: ifconfig.me — адрес сервера, 2ip.ru — российский адрес.

**Что делает скрипт** (чтобы отвечать на вопросы): ставит Xray (VLESS+REALITY Vision и XHTTP на TCP 443, Hysteria2 на UDP 443), nginx (сайт-прикрытие на 127.0.0.1:8443 и порт 80 для Let's Encrypt), сертификат Let's Encrypt (на имя сервера, а если его нет — на IP-адрес; продлевается сам), ufw, fail2ban, переносит SSH на случайный порт 40000–59999, включает автообновления с перезагрузкой в 04:30, собирает подписку для Happ с маршрутизацией «российское — напрямую» и полоской трафика (vnStat). Повторный запуск безопасен, ключи сохраняются.

**Если ошибка**
- Скрипт печатает «✗ Ошибка на шаге …» с причиной. Попроси прислать её и вывод `sudo tail -n 60 /var/log/vpn-setup.log`.
- Сертификат не выдан → почти всегда закрыт порт 80 файрволом в панели хостера. Нужно открыть входящие 80/tcp, 443/tcp, 443/udp и порт SSH, затем повторить команду.
- «порт 443 занят» → сервер поставлен с готовым веб-сервером или панелью. Переустановить сервер в панели хостера с чистым образом Ubuntu 24.04 и повторить.
- Обрыв связи во время установки → зайти снова и повторить ту же команду.
- Не пускает по SSH после установки → новый порт: `ssh -p ПОРТ …`. Порт можно узнать через веб-консоль хостера: `sudo vpn-info`. Вернуть 22: команда установки с `SSH_PORT=22`.
- VPN не подключается: попросить вывод `sudo vpn-info` (все службы должны быть `active`) и `sudo journalctl -u xray -n 30 --no-pager`. Предложить по очереди серверы Hysteria2 → XHTTP → Vision в Happ и сменить сеть (Wi-Fi ↔ мобильная).

**Чего не делать:** не править конфиги Xray и nginx вручную (при следующем запуске скрипт их перезапишет — меняйте настройки через параметры команды); не советовать отключать файрвол; не просить человека публиковать ссылки `…/sub` и `…/add` — достаточно их начала до секретной части.

## Что где лежит на сервере

| Путь | Что это |
|---|---|
| `sudo vpn-info` | ссылки, QR-код, состояние служб, расход трафика |
| `/etc/vpn/` | настройки, ключи (не показывайте посторонним) |
| `/usr/local/etc/xray/config.json` | конфигурация Xray (собирается скриптом) |
| `/var/log/vpn-setup.log` | журнал установки |
| службы | `xray`, `nginx`, `fail2ban`, `vnstat`; таймеры `vpn-sub-update` (полоска трафика, каждые 5 минут), `vpn-certbot` (продление сертификата), `vpn-geodata` (базы адресов, раз в месяц) |

Проверено на Ubuntu 22.04 и 24.04, Debian 12 и 13 (Xray 26.10.31).
